Pimalaya

Pimalaya is an ambitious project that aims to improve open-source tools related to Personal Information Management (also known as PIM), which includes emails, contacts, calendars, tasks and more.

Objectives

  1. Provide I/O-free Rust libraries dedicated to the PIM domain. They serve as a basis for all sorts of top-level applications, which prevents developers from reinventing the wheel.
  2. Provide quality house-made applications built on top of these libraries, gathered into projects.
