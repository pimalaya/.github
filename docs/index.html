Pimalaya

Open-source PIM tools, written in Rust.

Pimalaya is an ambitious project that aims to improve open-source tools related to personal information management (also known as PIM), which includes emails, contacts, calendars, tasks and more. It provides I/O-free Rust libraries dedicated to the PIM domain, which prevents developers from reinventing the wheel, and quality house-made applications built on top of them.
